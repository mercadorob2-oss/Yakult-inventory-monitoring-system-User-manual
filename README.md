# Yakult Inventory System - Web User Manual

## 📚 Overview

This is the complete web-based user manual for the Yakult Inventory Management System (YIMS). The manual provides comprehensive documentation for all system features and functionality.

## 📁 Files Included

- **index.html** - Main user manual page with navigation and content
- **itcm.html** - IT Call Monitoring (ITCM) user manual page
- **borrow.html** - Borrow Items user manual page
- **styles.css** - Professional styling and responsive design
- **script.js** - Interactive features and smooth navigation
- **IMAGES/** - Desktop app screenshots (YIMS)
- **ITCM-IMAGES/** - IT Call Monitoring screenshots (ITCM)
- **images-mobile/** - YakultScanner/mobile screenshots
- **borrow_images/** - Borrow Items screenshots

## 🚀 How to Use

### Option 1: Open Directly
Simply double-click `index.html` to open the manual in your default web browser.

### Option 2: From Application
You can link to this manual from within the application by adding a "Help" menu item that opens this file.

### Option 3: Deploy to Web Server
For organization-wide access, deploy these files to your internal web server or SharePoint.

The user manual covers:

## 🎨 Customization

### Updating Content
To add or modify content:
1. Open `index.html` in a text editor
2. Locate the section you want to edit
3. Modify the HTML content
4. Save and refresh in browser

### Changing Colors
To match your branding:
1. Open `styles.css`
2. Modify the CSS variables at the top:
   ```css
   :root {
       --primary-color: #e31e24;  /* Yakult red */
       --secondary-color: #2c3e50; /* Dark blue-gray */
       /* ... other colors */
   }
   ```

### Adding Images
To add screenshots or diagrams:
1. Place images in the `UserManual` folder
2. Reference in HTML:
   ```html
   <img src="screenshot.png" alt="Description">
   ```
