Borrow Items

Borrowing and returning serialized assets in YIMS

Overview

▼

What is Borrow Items?

Borrow Items is the YIMS desktop module used to log borrowed and returned serialized assets. It records who borrowed the item, which department they belong to, who encoded the transaction, and when the item was borrowed or returned.

Borrow Logging

Log borrowed items by serial number.

Return Logging

Close open borrow records when items are returned.

Open Borrows

Track items that are still out.

History

Review completed borrow and return activity.

Dashboard Layout

▼

Main Screen Areas

  • Borrow Item panel: resolve a serial and log a new borrow
  • Return Item panel: find an open borrow and return it
  • Open Borrows tab: currently borrowed items
  • History tab: previously returned items
  • Top controls: search, refresh, paging, and export
Tip: This module is designed for fast scan-and-log workflows, so barcode scanners work well with the serial fields.

Borrow an Existing Item

▼

Borrow a Listed Inventory Item

  1. Go to the Borrow Item panel.
  2. Scan or type the Serial Number.
  3. Click Resolve.
  4. Check the item name and description shown by the system.
  5. Select the Company, Department, and employee.
  6. Click Borrow.
  7. Confirm the borrow details.
Important: If the item already has an open borrow record, the system should block another active borrow for the same item.

Add New Item and Borrow

▼

Borrow an Item Not Yet in Inventory

If the serial number is not found, the module can guide the user to create the item first, then continue with the borrow process.

  1. Enter a serial number that does not yet exist in inventory.
  2. Choose to add the item, or click Add New.
  3. Fill in the item details.
  4. Save the item.
  5. Select the borrower and finish the borrow transaction.
Note: This flow is useful for external, newly received, or not-yet-registered assets that must be borrowed immediately.

Borrower Selection Modes

▼

Listed Employee vs Not Listed

  • Listed employee: choose an existing employee from the dropdowns
  • Not listed: create a new employee and return to the borrow screen
Note: The employee should have a valid department assignment before the borrow is logged.

Return Item

▼

How to Return a Borrowed Item

  1. Go to the Return Item panel.
  2. Scan or type the serial number.
  3. Click Find Open.
  4. Review the open borrow information shown by the system.
  5. Select the employee returning the item.
  6. Click Return.
  7. Confirm the return details.
Tip: You can also select a row from the Open Borrows table and use Return Selected.

Open Borrows

▼

Current Borrowed Items

The Open Borrows tab lists all items that are still out and not yet returned.

  • Serial Number: item serial
  • Item Description: item name, model, and details
  • Borrowed By: employee who borrowed the item
  • Department: linked department
  • Elapsed: current borrow duration
  • Encoded By: user who logged the borrow
  • Borrowed: borrow date and time

History

▼

Completed Borrow Transactions

Once an item is returned, its record moves into the History tab. This gives you a record of completed borrow and return activity.

  • Borrowed date/time
  • Returned date/time
  • Borrowed by employee
  • Returned by employee
  • Encoded by user

Search, Refresh, Paging, and Export

▼

Working with Records

  • Search: filter visible records
  • Refresh: reload the latest data
  • Prev / Next: move through pages
  • Export CSV: export the current tab for reporting
Note: Export applies to the currently visible list, either Open Borrows or History.

Troubleshooting

▼

Common Issues

  • Item not found: the serial number does not exist in inventory yet
  • Item is already borrowed: the item already has an open borrow record
  • No open borrow found: there is no active borrow record for that serial
  • Borrow schema missing: the borrow database objects are not installed
  • Employee has no department assigned: complete the employee profile first
Important: If the screen opens but borrows and returns cannot be logged, verify that the Borrow Items database schema has been installed correctly.
